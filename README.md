# 📖 MangaHub

A modern, responsive web application designed for browsing and reading manga online, built with **React**, **TypeScript**, and **Tailwind CSS**. MangaHub delivers a fast and seamless user experience with advanced search options, bookmarking, and reading history tracking.

---

## 🚀 Key Features

* **Manga Exploration:** Browse top-trending titles, filter by category/genre, and search for specific manga easily.
* **Responsive Reader:** Smooth chapter page rendering, optimized image loading, and mobile-friendly navigation.
* **Bookmarks & History:** Save favorite series and maintain reading history using browser local storage.
* **Modern UI/UX:** Clean, dark-mode accessible interface tailored for comfortable long-duration reading.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS
* **Routing:** React Router
* **State & Storage:** React Hooks, LocalStorage API
* **Build Tool:** Vite

---

## ⚙️ Quick Start

Follow these steps to set up and run the application locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/khang04dev/MangaHub.git
   ```

2. **Navigate to the project root:**
   ```bash
   cd MangaHub
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **View in browser:**
   Open your web browser and go to `http://localhost:5173` (or your Vite local server URL).
